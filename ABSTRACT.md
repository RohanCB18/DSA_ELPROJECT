# Abstract

Data structures are fundamental to algorithm design, yet their practical applications often remain abstract in traditional academic settings. This project addresses the gap in experiential learning by developing an Intelligent Transport Simulation System that demonstrates five fundamental data structures—weighted graphs, linked lists, hash maps, max-heap priority queues, and queues—solving urban transportation challenges through interactive visualization. The objective is to bridge theoretical knowledge with practical implementation in a real-world transport optimization context.

The system employs a full-stack architecture with a C backend and Next.js frontend. The backend implements a weighted graph (6×6 adjacency matrix) representing the city map, a max-heap priority queue for congestion detection, and event-driven simulation logic. The frontend provides an operator console, SVG city map visualization, and live representations of all five data structures: linked lists (passenger tracking, capacity: 10), hash maps (station states), max-heap (congestion priorities), and queues (route progression). The C backend communicates via WSL, emitting structured event streams parsed by the JavaScript frontend for real-time updates.

The implementation successfully demonstrates all five data structures with real-time visual feedback. The max-heap correctly prioritizes stations by congestion (O(log n) operations), and the system handles 30 simulation steps with sub-second response times using greedy boarding algorithms. Visual representations update synchronously with backend state changes, providing 100% operational visibility compared to static textbook diagrams.

The project successfully bridges theoretical knowledge and practical implementation, offering an experiential learning tool for data structures education. Future enhancements include multi-bus support with dynamic routing algorithms, larger network simulations (15+ stations), and educational assessment modules to quantify learning outcomes.
